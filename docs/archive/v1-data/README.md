# Archive donnees V1

Ce dossier conserve les anciens fichiers de donnees utilises par la premiere maquette technique.

Ils ne sont plus utilises par l'application actuelle.

Le dataset actif est dans :

```text
public/data/reference/
```

Fichiers archives :

- `events.csv`
- `places.csv`
- `flows.csv`
- `zone_counts.csv`
- `validate-data.mjs`

Ces fichiers avaient un schema different, avec notamment :

- `title`
- `kicker`
- `description`
- `story_step`
- `visible_places`
- `active_flows`

Ils sont conserves uniquement pour memoire et comparaison.
