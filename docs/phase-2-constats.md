# Constats phase 2

## Bilan positif

- L'orientation editoriale est conforme a l'intention du projet.
- Le vocabulaire de prudence est pose.
- Les champs de statut, de source et de certitude sont documentes.
- Les divergences INSP/OMS du 20 mai sont explicitement conservees.
- Les lieux approximatifs sont signales comme tels.

## Limites constatees

- Peu de points bloquants a ce stade.
- La methode est solide, mais elle devra etre testee dans l'interface : une bonne regle editoriale ne suffit pas si elle n'est pas visible pour le lecteur.
- Les documents sources devront encore etre relus finement avant enrichissement complet des donnees.

## Decision

La phase 2 est consideree comme validee. La phase 3 peut porter sur la mise en recit interactive : sequences, cadrages cartographiques, notes d'incertitude visibles et transitions narratives.
