# Constats phase 3

## Bilan positif

- Les 6 sequences narratives sont maintenant portees par les donnees.
- Chaque sequence dispose d'un cadrage cartographique propre.
- Les lieux visibles et les flux actifs sont controles depuis `events.csv`.
- Les notes d'incertitude sont visibles dans le panneau narratif.
- Le recit commence a mieux distinguer symptomes, alerte, confirmation et extension regionale.

## Limites constatees

- Le rythme visuel reste encore perfectible.
- Les transitions cartographiques sont fonctionnelles, mais pas encore vraiment mises en scene.
- Le design general reste proche du prototype technique.
- Les chiffres par zone ne sont pas encore exploites visuellement.

## Decision

La phase 3 est validee comme structure narrative de base. La phase 4 doit maintenant donner une grammaire cartographique plus lisible : styles, bulles proportionnelles, arcs typologies, tooltips et avertissements visuels.
